# Fashion-store-suite
Aplicación web full-stack para una tienda de moda que incluye catálogo de comercio electrónico, sistema de reservas para asesoría de imagen y panel de administración. Desarrollada como proyecto de portafolio (DAW).

[![Status](https://img.shields.io/badge/Status-In%20Development-orange)](#)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](#)

> **Fashion Store Suite** es un proyecto personal Fullstack orientado a resolver la gestión digital de una tienda de ropa moderna. Integra la venta de catálogo online (E-commerce), un sistema de reservas para asesorías de imagen (Personal Shopper) y un panel de administración unificado para la gestión del negocio.

---

## 🎯 Visión General y Funcionalidades

El objetivo de esta aplicación es ofrecer una experiencia completa tanto para el cliente final como para el administrador de la tienda.

### 🛒 Módulo E-Commerce (Cliente)
- Catálogo interactivo de prendas con filtros por categoría, marca, color y talla.
- Vista detallada de productos.
- Carrito de compras funcional y persistente.

### 📅 Módulo de Reservas
- Agendamiento de citas con estilistas y Personal Shoppers.
- Selección de fechas y franjas horarias disponibles sin solapamientos.
- Formulario de confirmación y datos de contacto.

### 📊 Dashboard de Administración (Backoffice)
- Autenticación segura para administradores.
- Panel CRUD completo para la gestión del catálogo de productos.
- Vista general de la agenda de citas y clientes.
